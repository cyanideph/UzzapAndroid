## What this project is

KOTLINJARZAP is an independent Android/Kotlin recreation of the classic Nokia/J2ME Uzzap mobile chat experience. The modern Android implementation, Supabase integration, and other newly written code in this repository are developed by CY unless a file or dependency states otherwise.
