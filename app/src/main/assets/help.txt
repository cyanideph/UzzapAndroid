UZZAP HELP

Welcome to Uzzap!
This guide explains the current Android version of Uzzap and the features available in the app.

1. GETTING STARTED

• Sign Up: Create a Uzzap account and complete your profile.
• Log In: Sign in with your Uzzap account.
• Password Recovery: Use password recovery if you cannot sign in.
• Session: Uzzap keeps your session so you can return to the app without signing in every time.
• Log Off: Use Options > Log Off when you want to end the current session.

2. YOUR PROFILE

Open your profile/settings to manage your Uzzap identity.
You can update your profile information, avatar and status/presence.
Your online/offline presence can be shown to other users when available.

3. PHILIPPINE CHATROOMS

Uzzap organizes public chatrooms by Philippine region and province.

• Choose a Region.
• Choose a Province.
• Join the province chatroom.
• Read and send messages in the room.
• Leave the room when you are finished.

The room list is designed around Philippine regions and provinces rather than the old room structure.

4. PUBLIC ROOM CHAT

Inside a room you can:

• Send messages.
• Receive new messages in real time when connected.
• Refresh room messages.
• View room participants.
• Use available emoticons.
• Report a message or user when necessary.
• Invite a buddy to a room when invitations are available.
• Leave the room.

Some messages may be generated by uzzapbot, including room join/leave or system messages.

5. BUDDIES

Use the Buddy List to manage people you want to contact quickly.

• Add a buddy.
• Remove a buddy.
• See available presence information.
• Open a private chat.
• Block a user.
• Report a user.

6. PRIVATE CHAT

Private Chat lets you communicate one-to-one with another Uzzap user.

• Open a buddy.
• Start Private Chat.
• Send messages.
• See message status when available.
• Sent = the message was sent.
• Read = the recipient has opened/read the message when read receipts are available.
• Unread messages can be tracked by the app.

7. MESSAGE RECEIPTS

Uzzap supports delivery/read status for supported private messages.
You can open the Message Receipts screen from the Instant Messaging options to review recent outgoing messages and their status.

8. ROOM INVITATIONS

You may receive an invitation to join a room.
Open Room Invitations to review pending invitations and accept or decline them.

Only authorized actions are allowed by the server. A user cannot bypass room membership or moderation rules by changing the Android app.

9. REPORTING AND SAFETY

If you see inappropriate content or a user who violates the rules:

• Use Report to submit a report.
• Give a clear reason when requested.
• Block a user if you do not want to interact with them.

Reports can be reviewed by authorized moderators.

10. MODERATION

Moderators help keep Uzzap rooms safe and organized.
Depending on your role, the Moderator Console can provide:

• Report Queue
• Message deletion
• Warn
• Mute
• Kick
• Ban
• Active sanctions
• Sanction expiry
• Sanction revoke
• Moderation audit history

Admins can manage moderator assignments. A moderator-only room is restricted to authorized moderators/admins.

Moderation permissions are enforced by the Uzzap backend, not only by the Android interface.

11. MODERATOR-ONLY ROOM

The Moderator Room is a restricted room for moderators and administrators.
Regular users cannot enter it simply by attempting to access the room from the client.

12. NOTIFICATIONS AND PRESENCE

Uzzap can use notifications for supported messaging/activity events.
Presence information may update as users connect, disconnect or refresh their status.

Android notification permission may be required for notifications on supported Android versions.

13. OFFLINE AND CONNECTION RECOVERY

If your connection is interrupted:

• Check your network connection.
• Retry the affected action.
• Refresh the current screen when available.
• Return to the room or chat if necessary.

Uzzap is designed to preserve important local state and recover gracefully from temporary connection problems.

14. RATE LIMITING AND SECURITY

Uzzap uses server-side security controls to protect messaging and moderation features.
Examples include message rate limits, room participation rules and database row-level security (RLS).

Do not share your password, authentication tokens or private account information with anyone.

15. SETTINGS AND OTHER FEATURES

The Main Menu provides access to supported settings and tools, including:

• Settings
• Silent Mode
• Themes
• Help
• Battery Saving
• Extended Messaging
• Instant Messaging
• Chat Rooms
• Change Status
• Room Invitations
• Message Receipts
• Moderator tools when authorized
• About Uzzap

Some legacy features from the original Java/mobile client are not part of the current Android implementation. The current Help page describes the features actually supported by this Uzzap Android project.

16. ABOUT UZZAP

Open Options > About Uzzap to view:

• Current app version.
• Build number.
• What's New.
• Complete feature list.
• Version history.
• Uzzap project information.

17. WHAT'S NEW AND VERSION HISTORY

The About Uzzap screen contains the current release notes and previous version history so users can see how Uzzap has evolved.

When a new version is released, its changes should be added to the version history and What's New section.

18. REPORT A PROBLEM

If something does not work:

1. Check your internet connection.
2. Try refreshing the screen.
3. Close and reopen the affected feature.
4. Check whether the issue affects only one room/chat or the whole app.
5. Report the problem with enough information to reproduce it.

Never include your password or private authentication credentials in a bug report.

19. IMPORTANT SAFETY NOTE

Be respectful to other users. Do not share sensitive personal information in public rooms. Use Block and Report when appropriate.

20. UZZAP PROJECT

Uzzap is a modern Kotlin Android recreation/continuation project inspired by the classic Smart Uzzap experience.
The current application uses a secure cloud backend and includes modern authentication, chat, buddy, private messaging and moderation features.

Created by CY.

For the current implementation and release information, use Options > About Uzzap.
21. MESSAGE COLORS

Messages support 30 Uzzap color codes (c01 through c30). Multiple colors can appear in one message. Colors apply to message text only; nicknames stay text-only.

22. WHISPERS ARE PRIVATE

The Whisper option in a room sends a true one-to-one private message. It is not shown to the room.

23. NOTIFICATION PERMISSION

On Android 13 and newer, the app asks once for notification permission so private messages, buddy requests and invitations can alert you. If you decline, the app asks at most one more time and then never nags; you can enable notifications later in Android Settings.

24. DELETE YOUR ACCOUNT

Settings > Privacy > Request Account Deletion permanently removes your profile, buddy list and message history. If you cannot open the app, use the web deletion page linked from the Uzzap website.
