# Uzzap Account Deletion

Uzzap provides an in-app account deletion option and an external web-based account deletion request resource.

When a verified deletion request is completed, Uzzap deletes the account and associated user data, subject to limited retention required for legitimate security, fraud-prevention or legal reasons.

External deletion resource:

https://hrjgblvxhtbopuyzyasu.supabase.co/functions/v1/uzzap-privacy?delete=1

The external resource is intended for users who have uninstalled the application or cannot access the in-app deletion path.
